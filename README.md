# Вычисление суммы степеней чисел от 0 до n

Вычисляемое математическое выражение:

Результат выводится на экран в виде вещественного числа.

## Логическая часть
Для реализации вычислений используется циклическая структура:
1. Переменная суммы `s` сбрасывается в `0`, счётчик цикла `i` начинается с `0`.
2. Цикл выполняется до тех пор, пока счётчик `i` <= `n` (`i <= n`).
3. На каждом шаге к текущей сумме `s` прибавляется значение `pow(i, k)`
4. На каждой итерации счётчик `i` увеличивается на 1 (`i++`).
